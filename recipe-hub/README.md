# 🍳 Recipe Hub — рецепты, холодильник и режим готовки

Сайт на чистом HTML + CSS + JavaScript (без сборки и зависимостей).

## Возможности

**📖 Каталог рецептов** — 18 блюд, фильтры по категории, времени и калориям, поиск по названию и ингредиентам, избранное (`localStorage`).

**🧊 Мой холодильник** — отметьте продукты, которые есть дома, выберите приём пищи (завтрак / обед / ужин / десерт) и получите подходящие блюда:
- сколько продуктов из рецепта уже есть и чего не хватает;
- режимы показа: «готовить можно сейчас», «не хватает до 2 продуктов», «хоть что-то из моих продуктов»;
- блюда сортируются по полноте набора и близости к вашей норме калорий.

**👤 Регистрация, вход и профиль** — тип питания (обычный / вегетарианский / веганский), аллергии (глютен, молоко, яйца, орехи, рыба, соя, кунжут), нелюбимые продукты, дневная норма калорий (можно рассчитать по росту, весу и активности), обычное число едоков. Неподходящие блюда скрываются, а нужные продукты в холодильнике помечаются предупреждением. Гость тоже может задать предпочтения.

**🔥 Точная калорийность** — калории каждого блюда считаются автоматически по составу: для каждого продукта известны ккал на 100 г, вес «штуки» и ложек (`js/products.js`). В рецепте видно количество и калории каждого ингредиента.

**👥 Количество человек во всех разделах** — переключатель «Едят: N». Сайт сам считает, сколько порций нужно, чтобы каждому хватило калорий на выбранный приём пищи (норма на день × доля приёма: завтрак 25%, обед 35%, ужин 30%, десерт 10%). В окне рецепта можно поменять число человек, приём пищи или порции вручную — граммовка и калории пересчитываются мгновенно.

**👩‍🍳 Режим готовки** — крупные кнопки «Назад / Далее», таймер обратного отсчёта (`setInterval`), голосовые подсказки (Web Speech API), экран не гаснет. Горячие клавиши: `←` `→`, `Пробел` (таймер), `V` (повторить голосом), `Esc`.

## Как открыть в IntelliJ IDEA

1. `File → Open…` → выберите папку `recipe-hub`.
2. Откройте `index.html` и нажмите значок браузера в правом верхнем углу редактора.
3. Голос лучше всего работает в Chrome / Edge.

```
recipe-hub/
├── index.html          — разметка
├── css/
│   ├── style.css       — основные стили
│   └── features.css    — вкладки, холодильник, формы, профиль
└── js/
    ├── data.js         — первые 12 рецептов
    ├── recipes2.js     — ещё 6 рецептов + к каким приёмам пищи подходит каждое блюдо

    └── app.js          — интерфейс и вся логика
```

## Как добавить рецепт

Добавьте объект в `RECIPES` (например, в `js/recipes2.js`) и впишите его в `RECIPE_MEALS`.
Калории, аллергены и тип питания считаются сами — достаточно, чтобы названия ингредиентов были в базе продуктов:

```js
{
  id: 'my-recipe', title: 'Название', emoji: '🍕', color: '#fde7c2',
  categories: ['main'],            // breakfast | dessert | vegan | main
  time: 30, servings: 2, calories: 0,
  description: 'Короткое описание',
  ingredients: [{ name: 'мука', amount: 200, unit: 'г' }],   // unit: г, мл, шт, ст. л., ч. л.; amount: null = «по вкусу»
  steps: [{ text: 'Шаг без таймера' }, { text: 'Шаг с таймером', timer: 300 }]
}
```

Если продукта нет в базе, в консоли браузера появится предупреждение `Неизвестный ингредиент` — добавьте его в `PRODUCTS` в `js/products.js`.
Соль, вода, специи и разрыхлитель считаются «всегда есть на кухне» (`PANTRY_RX`).

## Важно

- Аккаунты и данные хранятся **только в браузере** (`localStorage`) — на другом устройстве их не будет. Пароль хранится в виде хеша с «солью», но это учебная защита: для настоящего сайта регистрацию нужно делать на сервере.
- Калорийность приблизительная (по средним табличным значениям продуктов в сыром виде) и не заменяет консультацию врача или диетолога. При серьёзной аллергии всегда проверяйте состав продуктов на упаковке.
